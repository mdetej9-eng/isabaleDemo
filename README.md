# Салон красоты «Исабаль» — сайт-визитка

Одностраничный сайт-визитка для салона красоты «Исабаль» (г. Ставрополь, ул. Тухачевского, 26/4).

## Стиль

Editorial light: песочный фон, жжёная охра, шрифты Unbounded + Manrope. Сплит-герой с рейтингом 4.7★, нумерованные списки услуг, галерея с лайтбоксом.

## Что внутри

- **Плашка «Демо-концепт»** в углу — сайт сделан заранее для презентации
- **Сплит-герой** с фото работы и чипом рейтинга **4.7 в 2ГИС (36 отзывов)**
- **Услуги** — нумерованные строки 01–04: парикмахерская, ногти, косметология, визаж и брови
- **О салоне** с фото входа и статистикой
- **Наши работы** — галерея 8 фото с лайтбоксом
- **Контакты**: блок с двумя телефонами, адрес, отзывы в 2ГИС

## Технологии

Чистый HTML + CSS + JavaScript, без сборщиков и зависимостей.
